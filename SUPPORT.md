# Support

There is no public support channel for this account — every repository is privately owned and
operated by `spencer-shadley`.

- **Found a defect or have a request for a specific repository?** Open an issue there using the
  account-wide [task form](https://github.com/spencer-shadley/.github/blob/main/.github/ISSUE_TEMPLATE/task.yml).
  File in the repository whose policy or implementation must change. Issue-form content and
  account-default ownership defects belong in `spencer-shadley/.github`; bootstrap/materialization
  defects belong in `repo-template`.
- **Changing intake or filing through an agent?** Read the canonical
  [intake guide](https://github.com/spencer-shadley/.github/blob/main/docs/governed-intake-ssot.md).
  Do not create a local template fallback or mistake the YAML definition for a rendered issue body.
- **A genuine human decision is required?** Use a governed `human-required` GitHub issue carrying
  the exact decision, tradeoffs, recommendation, and unblock condition under Code's current
  `stamp-human-required` process. An out-of-band notification does not replace that durable issue.
  Routine agent-owned work does not become a human escalation merely because a tool is unavailable.
