# Code of conduct

Every repository under this account is privately owned and operated by `spencer-shadley`. This is
not a public open-source community with outside contributors, so this file is short and honest
rather than a copied community covenant.

If you are a human collaborator with write access: be direct, cite evidence, and prefer fixing
forward over blame. If you are an autonomous agent operating in this account: follow the
repository's `AGENTS.md` and this account's [`issue-intake.md`](https://github.com/spencer-shadley/code/blob/master/docs/guides/issue-intake.md)
law — conserve findings, do not fabricate evidence, and escalate only genuine human decisions.

Anyone interacting with these repositories (issues, PR comments, discussions) is expected to keep
communication factual and non-abusive. There is no formal enforcement ladder because there is no
public community to moderate; report a problem via [SUPPORT.md](SUPPORT.md).
